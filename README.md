# 🌐 100x Systems Foundations & Engineering Labs

Master practice and production repository for Phase 1 of the 18-to-24-Month Systems Roadmap.

> **📍 Full 24-Month Master Roadmap:** Read [MASTER_SYSTEMS_ROADMAP.md](./MASTER_SYSTEMS_ROADMAP.md) for the complete 5-Phase architectural progression from Web Dev & DSA to DevOps, eBPF, and Project Honeypot.

## Architecture & Progression Structure

* **`01-html-css-dom-internals/`**
  * Core semantic layout, CSS Box Model, Flexbox/Grid architectures, responsive systems, and DOM tree mechanics.
* **`02-async-js-runtime/`**
  * V8 engine internals, call stack, callback queue, microtask queue, Event Loop, Promises, and Node.js asynchronous architecture.
* **`03-backend-microservices/`**
  * HTTP servers, REST APIs, Express/Hono, PostgreSQL, and Prisma ORM.
* **`04-devops-infra/`**
  * Linux internals, Docker containers, Kubernetes, CI/CD, Nginx, and cloud deployment.
* **`05-distributed-systems/`**
  * Redis caching/pub-sub, Kafka streams, WebSockets, rate limiters, and system design.
* **`06-cyber-deception-engine/` (Project Honeypot)**
  * Linux eBPF kernel probes, anomaly detection, automated decoys, and real-time CISO threat console.
